# Topic Pulse Agent 测试集与功能规格

`test_case` 目录用于维护 Topic Pulse Agent 的业务验收标准。它不是单元测试代码，而是一套面向人工测试、端到端测试、Prompt 回归和工具链路回归的功能规格。

## 目录结构

- `functional_spec.md`：Agent 功能规格，包含任务边界、任务路径、工具调用规则、Markdown 记忆规则、输出规则。
- `test_set.md`：Agent 验收测试集，包含正向集、边界集、干扰集和观测检查点。

## 使用方式

每次修改以下内容后，都应对照本目录进行回归：

1. `ReActConfig.system_prompt`
2. 工具描述、工具参数、工具返回结构
3. ReAct 工具选择、参数修复、上下文组装逻辑
4. Markdown 话题记忆的创建、读取、更新逻辑
5. Web/CLI 多轮对话链路
6. trace 日志、引用数据、新旧信息标识等可观测能力

## 验收关注点

- 是否按用户意图正确选择工具。
- 普通查询是否避免误写入 Markdown。
- 已关注话题是否能被召回、读取、联网更新并合并。
- 生成的 Markdown 是否结构完整、时间线倒序、来源和链接可追溯。
- 最终回答是否包含 Web 展示需要的结构化字段。
- 流程是否能稳定结束，前端是否能收到最终 `done` 事件。
